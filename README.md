## EEG ADHD

This project processes EEG data from an ADHD dataset, applies signal preprocessing and multi-resolution analysis, and extracts features for classification.

The dataset used is from Mohammadi Nasarbadi et al., recorded at 128 Hz across 19 EEG channels from ADHD and control subjects.

## Files and Folders

### core/

Shared Python modules used across the project.

- **`EegDataset.py`** - A dataclass that holds dataset-level metadata: name, sampling frequency, number of participants, number of channels, ADHD and control counts, channel names, and paths to raw, interim, and metadata directories.

- **`EegSubject.py`** - A dataclass for storing per-subject EEG data.

- **`preprocessing.py`** - Signal preprocessing functions: a Butterworth bandpass filter, a notch filter for powerline noise removal, and a function to segment continuous EEG signals into fixed-length windows.

- **`feature_extraction_metrics.py`** - Feature extraction functions for EEG signals. Currently implements statistical time-domain features (mean, std, variance, skewness, kurtosis, mean curve length, mean energy). Spectral band power which includes Band-Power Alpha, Theta, Delta, Gamma, Beta and Theta/Alpha ratio is implemneted along with log energy entropy, but other entropy ,easures, Hjorth parameters, difference features, and autoregressive model functions are defined but not yet implemented.

---

### builder/

Scripts that convert raw data into the processed formats used by the rest of the project.

- **`nasarbadi_builder.py`** - Reads the raw combined CSV file and splits it into per-subject CSV files saved under `datasets/interim_data/nasarbadi/`. Also generates a subject index CSV at `datasets/metadata/nasarbadi_subject_index.csv` with each subject's ID, class label, recording duration, and sample count.

---

### datasets/

All data files. The contents of this folder are not committed to version control.

- **`raw_data/`** - Contains the original raw dataset file (`adhdata.csv`), which has all subjects combined in a single CSV with `ID` and `Class` columns.

- **`interim_data/nasarbadi/`** - Per-subject CSV files generated by `nasarbadi_builder.py`. Each file contains only the EEG channel columns for that subject.

- **`adhd-aid-data/`** - Processed NumPy arrays generated by `Papers/adhd-aid-rep.py`. Each subject is saved as a `.npy` file with shape `(channels, segments, samples)`. VMD decomposition outputs are saved in a `vmd/` subfolder with shape `(channels, segments, IMFs, samples)`.

- **`metadata/`** - Contains `nasarbadi_subject_index.csv`, a lookup table of subject IDs, class labels, durations, and sample counts.

---

### papers/

Scripts and notebooks that replicate and explore published EEG-ADHD analysis methods.

- **`adhd-aid-rep.py`** - Replication script for the ADHD-AID paper (Attallah 2024). Loads per-subject interim data, applies bandpass and notch filtering, segments the signal into 4-second windows, saves the result as NumPy arrays, and then runs Variational Mode Decomposition (VMD) on each segment to extract intrinsic mode functions (IMFs).

- **`adhd-aid.ipynb`** - Notebook version of the ADHD-AID replication pipeline.

- **`data_exploration.ipynb`** - Notebook for initial exploration of the raw dataset.

---

### Root Files

- **`nasarbadi_helper.py`** - Utility functions used by scripts in `Papers/`. Provides `get_dataset_info()` to load dataset metadata and `get_subject_info(subject_id)` to load a single subject's interim CSV along with their class label.

- **`requirements.txt`** - Python dependencies: `numpy`, `pandas`, `scipy`, `matplotlib`, `PyWavelets`, `mne`.

- **`ADHD_EEG - mohammadi_nasarbadi.pdf`** - Literature review on the Nasarbadi EEG ADHD dataset.

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

To run the ADHD-AID replication script:

```bash
python papers/_adhd_aid_/adhd-aid-rep.py
```

The builder script (`builder/nasarbadi_builder.py`) only needs to be run once to generate interim data from the raw CSV. That step is already done and the output files are in place.

## Dataset Notes

- Sampling frequency: 128 Hz
- EEG channels: 19
- Subject columns in raw data: `ID` (subject identifier), `Class` (ADHD or Control)
- Segment length used in processing: 4 seconds (512 samples per segment)
- VMD decomposition: 9 IMFs per segment
